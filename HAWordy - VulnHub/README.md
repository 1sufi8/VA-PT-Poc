# HA Wordy - VulnHub

## Overview

This repository contains my penetration testing walkthrough and report for the **HA Wordy** vulnerable machine from VulnHub.

The assessment demonstrates the complete penetration testing lifecycle, including reconnaissance, enumeration, exploitation, reverse shell access, privilege escalation, and remediation recommendations.

> **Platform:** VulnHub  
> **Operating System:** Linux  
> **Difficulty:** Beginner to Intermediate

---

## Objectives

- Perform reconnaissance and service enumeration
- Identify vulnerable WordPress components
- Exploit an unrestricted file upload vulnerability
- Obtain a reverse shell
- Upgrade to a fully interactive TTY shell
- Perform local privilege escalation
- Gain root access
- Document findings and remediation
